What is SDV DreamCore?

In a modern car many functions are software that can be changed and updated like an app. DreamCore is our training model of such a car:

Jetson AGX Orinvehicle computer (HPC) · runs DreamCore, the KUKSA Databroker and the HMI
NXP GoldBox S32G399Azonal controller (ECU) · second node of the cluster
Raspberry Pi 4zone controller for our lights · drives LEDs and reads buttons
digital.auto Playgroundcloud tool in the browser · SDV code and dashboards

How the courses work

  • Next ▶ / ◀ Back or the arrow keys move through the steps.
  • 3D views: drag to rotate, mouse wheel to zoom.
  • Copy buttons copy commands exactly – no typing errors.
  • Show in full code opens every file with an explanation on every line.
  • Tick “I have done this step” – your progress is saved in this browser.

Safety rules

  • Change wiring only when the board is switched off.
  • Power last: 20 V only for the Jetson, 5 V only for the Pi.
  • Every LED with a 220 Ω resistor. GPIO pins are 3.3 V – never 5 V.
  • Never connect the bench to a real vehicle network.
  • Do not run commands you do not understand – ask first.

Before you start

  • Laptop with Chrome or Edge (Wi-Fi for the Playground).
  • Your own digital.auto Playground account (Course 3, module 2).
  • Bench logins: Jetson jetson, Raspberry Pi root – from your instructor.
  • Your bench’s runtime ID (shown on the DreamCore home page).
  • Work in teams of 2.
