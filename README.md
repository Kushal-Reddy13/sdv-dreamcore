## Publish on GitHub Pages
1. Create a repository (e.g. `sdv-dreamcore`).
2. Upload **all files of this folder** (including `.nojekyll`) to the root of the `main` branch.
3. Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save.
4. After 1–2 minutes the site is live at `https://<your-user>.github.io/sdv-dreamcore/`.

## Language
Use the **English / Deutsch** drop-down at the top right of every page. The choice is remembered in the browser.
